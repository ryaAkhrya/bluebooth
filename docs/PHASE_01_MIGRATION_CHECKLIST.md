# Phase 01 Migration Checklist

This checklist tracks local feature parity while the approved standalone prototype
remains available at `reference/mockup/index.html`.

- [x] 33 grid presets
- [x] 12 built-in frames
- [x] Camera access, switching, mirror, adjustments, fit, and fallback
- [x] 8 camera filters
- [x] 3, 5, and 10 second timer options and shot delay
- [x] Local countdown, capture, pause, cancel, retake, and restart flow
- [x] High-resolution canvas composition and PNG download
- [x] Local result save and previous-result display

Phase 01 is complete only after the checked features are available through the
Next.js application and lint, typecheck, and build pass.
